# TRABAJO INTELIGENCIA ARTIFICIAL: Clasificacion Asistida de Lesiones Cutaneas

## 1. OBJETIVO

El objetivo principal del proyecto es desarrollar un agente de soporte a la decisión médica para la detección y clasificación lesiones cutáneas a partir de imágenes digitales. El problema abordado es la variabilidad en el diagnóstico dermatológico inicial, buscando reducir el riesgo de que lesiones sospechosas pasen desapercibidas.

Para esta ocasión nos centraremos principalmente en el melanoma, que este es un tipo de cancer de piel, que puede aparecer como un lunar nuevo o como un lunar existente que cambia, buscando determinar si la lesión detectada es maligna (melanoma) o benigna (lunar común)
